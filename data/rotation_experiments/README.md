matching DIMACS `rotation.edge`, and a `report.json` with an explicit legal
five-coloring. All three graphs are SAT and cannot witness lower bound 6.

Each graph was generated by `quadratic_rotation_experiment.py`, with all
558,096 vertex pairs checked using integer coefficients in the declared
multiquadratic field. The four distinct prime square roots form an independent
basis, so a nonzero distance coefficient is a strict nonedge witness.

Each experiment tested extension of 128 canonical five-colorings of the source
graph, with zero blocked samples. These deterministic samples are not a uniform
sample or exhaustive enumeration of source colorings. The reported cross-edge
count includes edges incident to the shared origin; the table above removes
that bookkeeping effect.

expansion arguments, and reproduction commands.
