# 二邻居平移副本 CEGIS：实现计划

1. 为精确平移参数、跨边枚举和固定染色阻塞写失败测试。
2. 实现 `translated_copy_cegis.py`：
   - 从作者 `529.vtx` / `529.edge` 加载源图；
   - 从精确 \(r\) 生成两个单位圆交点；
   - 由 \(b=p\) 或 \(b=p+r\) 枚举完备跨边；
   - 对每条列明边再次验证平方距离严格为 1；
   - 对固定基图染色执行列表着色 SAT；
   - 对增广图执行不固定基图颜色的五染色 SAT。
3. 运行第一个精确副本，写出图、染色和 JSON 检查点。
4. 从 Heule 源顶点平移重合度筛选更多 \(r\)，逐个证明所用扩张不在
   \(K\)，运行可续接 CEGIS。
5. 对所有落盘图运行独立 `graph_verifier.py`；若通用数域后端过慢，加入
   一个不复用搜索代码的二次扩张验证后端。
6. 运行完整测试集并把命令、随机种子、哈希和失败分支写入
   `research_log.md`。
