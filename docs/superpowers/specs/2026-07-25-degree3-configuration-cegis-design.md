# 度 3 联合构形 CEGIS 设计

## 目标

第二阶段从首轮最后的 75 个已选候选和第 194 个基图 5-染色继续，不再
要求新增点单独看到五种颜色。候选池扩展为 Heule 529 每对单位圆的全部
精确恢复、基图度至少 3 的交点，并把候选之间的精确单位边纳入列表染色
SAT。

本阶段的成功条件有两种：

1. 增广图 5-UNSAT，输出 CNF、DRAT 和独立验证结果，进入潜在下界 6
   证书审计；
2. 某个基图 5-染色可扩展到整个候选池，输出完整显式 5-染色，严格排除
   当前候选池。

## 选择的方案

采用通用列表染色 SAT，而不是只枚举三角形或奇环。固定一个基图染色后，
每个候选的允许颜色是未出现在其基图单位邻居中的颜色；候选间单位边使用
普通异色约束。整个候选池不可列表染色时，通过逐点删除得到删除极小的
阻塞核。

这一方案覆盖单点、相邻点对、奇环及更一般的小构形。只枚举三角形更快，
但会遗漏已经发现的三点 V 型阻塞器；直接先接入 Snail 坐标域会同时改变
几何域和 SAT 逻辑，使失败原因不可分辨。

## 数据流

1. 从作者 529 坐标和边表重建基图。
2. 生成基图度至少 3 的单位圆交点；数值 KD-tree 只负责预筛，每个保留点
   和每条保留边都以符号平方距离等于 1 重新认证。
3. 从首轮 JSON 读取最终已选候选及停滞基图染色，并以精确坐标映射到新池。
4. 对当前基图染色求整个候选池的列表染色：
   - SAT：保存 529+全部候选的显式 5-染色并停止；
   - UNSAT：提取删除极小核，把核的全部顶点加入增广图。
5. 对增广图求普通 5-染色：
   - SAT：取新的 529 点限制作为下一反例；
   - UNSAT：写出 CNF/DRAT，并用独立 `drat-trim` 检查。

## 模块边界

- `configuration_cegis.py`：候选间边的预筛/精确认证、阻塞核提取、首轮状态
  恢复和第二阶段循环。
- `cegis.py`：继续提供精确候选生成与列表染色原语；修正报告中硬编码的旧
  候选池大小。
- `graph_verifier.py`：保持独立，不导入任何 CEGIS 模块。
- `tests/test_configuration_cegis.py`：覆盖精确候选边、三点 V 型核和首轮候选
  映射。

## 精确性边界

数值预筛可能漏掉理论候选或候选边，因此搜索停滞不是对全部平面点的证明。
任何声称的具体图和具体染色必须再由 `graph_verifier.py` 从坐标重建全部
单位边。只有完整图 5-UNSAT 且 DRAT/LRAT 独立通过，才可声称下界 6。

首个只读探测得到 532 个精确候选和 707 条精确候选间单位边。模型 194
对整个池列表染色 UNSAT；删除极小核为候选 `(98, 236, 504)`，其边为
`(98, 504)` 与 `(236, 504)`。
